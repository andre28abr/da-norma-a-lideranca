## 📖 O que é este repositório

Cada arquivo aqui é um modelo pronto: a tabela que se copia, se adapta e se leva para a reunião de
segunda-feira de manhã. Eles foram desenhados para serem usados **junto com o livro**, que explica o
que cada campo significa, quem preenche, o erro mais comum de cada instrumento e as decisões que
eles sustentam. Sem essa leitura, são tabelas soltas; com ela, viram o programa de governança da sua
organização.

**Onde comprar o livro:** [link da loja em breve]

**Link deste repositório, para citar e compartilhar:** `github.com/andre28abr/da-norma-a-lideranca`

Os PDFs são a versão formatada para imprimir e preencher. Os instrumentos que funcionam como
planilha de verdade (escalas, critério de aceitação, SoA, painel de KRI, temporalidade) existem
também em **XLSX editável**, para viver no dia a dia da operação.

## 🧭 Como usar

1. **Leia o capítulo indicado** na tabela acima: é lá que moram o contexto, os critérios e o erro
   mais comum de cada instrumento.
2. **Baixe o PDF** para imprimir e preencher, ou o **XLSX** quando quiser a versão viva na planilha.
3. **Adapte os números à sua realidade.** As faixas foram calibradas para uma organização de porte
   médio; o que se copia é a estrutura, os números você declara, e ao declará-los assume a
   responsabilidade por eles, que é o ponto.

Os materiais acompanham a **edição publicada** do livro (1ª edição, 2026) e não são atualizados fora
do ciclo de edições.
